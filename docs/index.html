What it is

MorphLive is an experimental prototype. As of 20 October 2026 it has not delivered convincing, realistic, real-time full-appearance transformation on the tested free, local Mac setup. The repository stays public as an experimental code and research record, not a finished or production-ready product.

The current live engine replaces inner facial features while hair, outer beard and head shape remain original. The brief guarded camera check ran around 6 FPS, and the whole-frame replacement candidate failed visual quality and speed acceptance.

Limits. Full appearance transformation is not implemented. The current model changes inner facial features, leaves beard, hair and head shape unchanged, and can paint over hands crossing the face when occlusion detection fails. These are known failures, not camera-setting problems. No engine or future performance is promised until it passes measured acceptance.

Features

Live webcam face replacement (GhostV2)

The default engine replaces facial features in each camera frame and keeps your live scene. A reference portrait supplies the target identity.

Curated adult personas

18 personas; public reference photos retain their original credits and licences.

Experimental virtual-camera route

Source includes output to an installed OBS Virtual Camera. Compatibility across Zoom, Meet and Teams has not been established.

Local DSP voice pairing

Independent pitch shifting, formant envelope control and a soft noise gate. These are generic DSP effects.

Local clip rendering

Export local videos up to five minutes with frame-by-frame face replacement, capped at 1080p / 30 FPS.

Local processing

No capture uploads or telemetry. Live capture is not recorded.

Privacy and safety

  • Processing stays local; there are no capture uploads or telemetry.
  • Camera and microphone do not start automatically, and a consent checkbox is required first.
  • Emergency stop or the Escape key releases every output immediately.
  • No real-person face or voice assets are included.
  • Do not use it for deceptive impersonation, unauthorised likeness replication or nonconsensual voice cloning.

Help wanted

Contributors and researchers are welcome. The goal is still realistic live appearance changes that follow expressions and movements. The primary target is free, local processing on Apple Silicon with 16 GB memory. Help is especially useful with:

  • A suitable whole-head video model or engine with clear model and asset licences.
  • Core ML, Metal or MLX implementations that improve completed-frame throughput without sacrificing natural texture, expression transfer or temporal stability.
  • Reliable foreground segmentation and hand-occlusion handling.
  • Reproducible latency, memory and received-video tests for Zoom, Meet or other video apps through a virtual camera.

Open an issue with a concrete proposal, or see the contribution guidance. Use fictional or consenting adult test subjects.

Quick start

Requirements: Node.js 24 or newer, npm, a webcam and a microphone. Live video also needs the separately installed native runtime, landmark model and a local reference (see the neural runtime guide).

Run from source

git clone https://github.com/Shahrukhalid/morphlive.git
cd morphlive
npm install
npm start

Or run ./start.sh on macOS/Linux or start.bat on Windows. No binary release is published and local packages are unsigned.

Frequently asked questions

Does MorphLive work?

Only partly. It has not delivered convincing, realistic, real-time full-appearance transformation. It replaces inner facial features, and the brief guarded camera check ran around 6 FPS. It is an experimental prototype, not a finished product.

Can it change my hair, beard or head shape?

No. Full appearance transformation is not implemented; hair, outer beard and head shape remain original.

Does it work in Zoom, Meet or Teams?

Not established. The source includes an experimental OBS Virtual Camera route, but compatibility across video-call apps has not been verified. The setup steps are integration instructions, not claims of completed tests.

Does it upload my video or audio?

No. Processing stays local, with no capture uploads or telemetry.

How can I help?

Open an issue with a concrete proposal or submit a focused pull request. Include the model and licence, minimum hardware, memory use, completed generated FPS and latency, test method and known limitations.

What hardware is it aimed at?

Free, local processing on Apple Silicon with 16 GB memory is the primary target. Windows hardware support is not established.

Is it safe to use for impersonation?

No. Use your own likeness or material you have permission to transform, and do not use MorphLive for deceptive impersonation, unauthorised likeness replication or nonconsensual voice cloning.
